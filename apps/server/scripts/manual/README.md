# Scripts Manuais

Utilitarios de uso ad-hoc para diagnostico e operacao local.

- `scripts/manual/check_email_config.py`: valida configuracao de envio de email.
- `scripts/manual/manual_test_prompts.py`: exercita endpoints de templates/prompt manualmente.
- `scripts/manual/local-database.sh`: helper para container local de Postgres.
- `scripts/manual/migrate.sh`: wrapper para rodar migracoes a partir da raiz do repositorio.

Esses scripts nao fazem parte do boot da API em producao.

AssessorAI Platform

Infraestrutura digital para operacao legislativa assistida por IA

Uma plataforma integrada para mandatos e equipes parlamentares com backend operacional, experiencia web e coleta automatizada de dados legislativos.

Ver arquitetura Explorar componentes

Backend

API central da plataforma com fluxos legislativos, geracao de documentos, autenticacao e console administrativo.

FastAPI + Streamlit

Frontend

Aplicacao web para uso cotidiano das equipes, com experiencia de produto e camada BFF para integracao segura com a API.

Next.js + React

Crawler

Coleta automatizada de proposicoes e metadados legislativos em multiplas casas, com operacao e monitoramento dedicados.

Scrapy + Scrapyd

Arquitetura

Um monorepo para tres frentes complementares

1. Coleta

O crawler captura dados legislativos, documentos e eventos de casas legislativas para alimentar processos internos.

→

2. Processamento

O backend organiza dados, aplica regras de negocio e habilita fluxos assistidos por IA para a operacao parlamentar.

→

3. Entrega

O frontend oferece a camada de uso diaria para assessores, gestores e operadores da plataforma.

Casos de uso

Onde a plataforma atua

  • Redacao e apoio a documentos legislativos
  • Gestao de mandatos e operacao administrativa
  • Busca de referencias normativas e politicas
  • Coleta e organizacao de dados legislativos publicos
  • Experiencias publicas e privadas para equipes e eleitorado
